# Permissions and contributions

This is a proprietary project maintained by [spinjitsu12](https://github.com/spinjitsu12). Public visibility is for presentation and review; the project is not open source. Read [LICENSE](LICENSE) before proposing reuse.

Request express written permission for any use beyond applicable law or GitHub's platform terms. Describe the files involved, intended use, distribution, and commercial context. Do not assume that attribution or a noncommercial purpose grants permission.

Discuss proposed contributions with the maintainer before submitting code or assets. Do not submit third-party content unless you have the rights needed for its proposed use. Contributions and their terms must be agreed with the maintainer separately.
